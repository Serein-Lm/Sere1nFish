# 社交地点图片采集

## 适用范围

- 用户要求收集某个地点、店铺、场所或景点的公开照片。
- 来源明确为美团、抖音的地点结果、公开评价或评论图片。
- 需要保留图片与其地点、发布内容、评价上下文之间的证据关系。

## 渐进式流程

1. 确认项目、地点、平台、采集目标和在线设备；多台设备时必须让用户指定。
2. 创建异步 Job 后立即返回 `job_id`、`task_id` 和排队状态，不重复下发。
3. 手机只执行公开搜索与只读浏览：列表候选先审核地点对应度，详情再次校验候选一致性。
4. 进入评价/评论图片查看器后逐张审核。地点对应不足、广告、头像、二维码、表情包、模糊图和无关推荐均丢弃。
5. 每张有效图片保存完整屏幕上下文和独立图片裁剪，并绑定平台、地点、关键词、候选、任务和记录 ID。
6. 查询完成状态后再读取图片结果；partial 必须同时报告成功平台和失败平台。

## 证据语义

- `full_context_screen`：完整手机屏幕，用于证明地点、评价/评论与图片的关系。
- `screen_render_crop`：从同一屏幕按视觉边界无损裁剪出的图片像素，不等于平台源文件或原始分辨率图片。
- `source_original_available=false` 时，回答中禁止使用“平台原图”“原始分辨率”等表述。

## 禁止动作

不得点赞、评论、收藏、关注、私信、下单、发布、上传或修改任何平台内容；不得绕过登录、权限、反爬或隐私控制；不得根据地点常识补造图片内容或评论。
