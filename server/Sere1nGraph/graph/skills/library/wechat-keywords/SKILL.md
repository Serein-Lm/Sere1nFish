# 微信公众号搜索词库

将 `{company}` 替换为目标公司的规范名、品牌简称或第一层全资子公司名称。搜索结果应进入文章，复制原始链接后交给浏览器池读取 HTML、图片和上下文。公众号搜索先发现官方主体和日常内容，再补充招采等业务线索，不能只搜索招投标。

## 核心检索模板

| 场景 | 搜索词模板 | 重点信息 |
| --- | --- | --- |
| 官方主体发现 | `{company}`、`{company} 公众号` | 官方账号、认证主体、账号历史文章 |
| 公开联络 | `{company} 联系方式`、`{company} 手机号码`、`{company} 座机`、`{company} 邮箱`、`{company} 联系人` | 公开披露的电话、邮箱、负责人、用途和邻近上下文 |
| 办公联络 | `{company} 办公室 电话` | 办公室、值班室、业务部门公开座机及用途 |
| 招采联络 | `{company} 招标 联系人`、`{company} 采购 联系方式` | 项目联系人、采购人、代理机构及归属上下文 |
| 招聘投稿 | `{company} 招聘 邮箱`、`{company} 投稿 邮箱` | 招聘、投稿、宣传等公开业务邮箱及用途 |
| 官方内容 | `{company} 新闻`、`{company} 公告` | 近期业务、机构动态、公开通知 |
| 合作联络 | `{company} 合作 联系方式` | 合作部门、联系人和公开联络方式 |

## 组合规则

1. 根公司与天眼查对外投资中的第一层全资子公司分别生成检索词，保留各自 `target_id` 和直接投资关系标注。
2. 优先使用品牌简称检索，同时保留企业规范全称用于确认归属。
3. 显式任务关键词优先，数据库词库用于补全，不覆盖用户输入。
4. 同一项目内按规范化空格去重；根公司和子单位的相同文章由原始链接去重。
5. 只采集正文公开披露且能明确归属于目标、目标部门或目标项目负责人的座机、手机号和邮箱，并保留用途与邻近上下文；不得推测、补全或获取非公开个人联系方式。
6. 手机查询预算较小时，优先保留“主体原名、公众号、联系方式、手机号、座机、邮箱、联系人”类检索词，再补充招采、招聘和合作场景。
7. 规范名和最多两个高置信简称用于主体发现；联系方式场景默认使用规范名，避免历史别名污染结果。
