# 数字人全双工语音与远端 OBS 接入

## 1. 百炼全双工语音

系统使用 `qwen-audio-3.0-realtime-plus`。浏览器只连接 Sere1nFish 的鉴权 WebSocket，后端再代理到百炼 Workspace；百炼 API Key 不会下发到浏览器。

该模型是实时语音对话模型：它听取麦克风输入，再使用系统音色或复刻音色生成 AI 回答。它不是逐字保留原话的实时 Voice Conversion 模型，不能把本人每句话无延迟地直接转换成另一种声线。

### 管理员配置

在“配置管理 -> 百炼实时语音”中维护 `cosyvoice` 配置段。最小配置如下：

```json
{
  "api_key": "<百炼 API Key>",
  "workspace_id": "<Workspace ID>",
  "region": "beijing",
  "realtime_model": "qwen-audio-3.0-realtime-plus",
  "realtime_voice": "longanqian",
  "realtime_turn_detection": "smart_turn",
  "realtime_max_history_turns": 20
}
```

`api_key` 也可以复用 `bailian.api_key`。敏感字段由配置中心加密保存，不写入 `.env`、日志或 Git。

可选字段：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `realtime_base_ws` | 根据 Workspace 生成 | 百炼 WSS 地址，后端统一修正为 `/api-ws/v1/realtime` |
| `realtime_instructions` | 空 | 会话默认指令，最多 4000 字符 |
| `realtime_vad_threshold` | `0.5` | `server_vad` 灵敏度，范围 `-1.0` 至 `1.0` |
| `realtime_vad_silence_ms` | `800` | 静音结束判定，范围 200 至 6000ms |
| `realtime_session_timeout_seconds` | `1800` | 单次会话最长时间 |

### 本机使用

1. 使用最新版 Chrome 打开 Sere1nFish HTTPS 页面。
2. 进入“AI 工具箱 -> 语音工具 -> 全双工对话”。
3. 展开“会话与本机设备”，选择 Mac/PC 的麦克风和扬声器。
4. 点击“开始对话”，在 Chrome 和操作系统中允许麦克风权限。
5. 普通环境使用“智能轮次”；外放回声或背景噪声较大时使用“按住说话”。需要语音打断时建议佩戴耳机。

浏览器输入为 16kHz、16-bit、单声道 PCM，百炼输出为 24kHz、16-bit、单声道 PCM。后端不保存原始会话音频或转写，只记录会话状态、耗时和字节数。

### 复刻音色

创建音色时选择“全双工对话”。全双工音色必须以 `qwen-audio-3.0-realtime-plus` 为目标模型创建；TTS 音色不能混用。创建前必须确认已获得声音所有者授权。

## 2. 远端换脸与目标音色接入本机 OBS

远端 GPU 和百炼都通过 Sere1nFish 后端接入。服务端把换脸图片帧与全双工回答的 24kHz PCM 音频写入同一个短时媒体输出会话，OBS 通过一个 HTTPS 浏览器源订阅。OBS 不需要 GPU 地址、GPU Token、百炼 API Key，也不需要增加公网入站端口。

### Sere1nFish 端

1. 使用 Mac/PC 的最新版 Chrome 登录 Sere1nFish。
2. 进入“AI 工具箱 -> AI 换脸 -> 实时摄像头”。
3. 选择已授权的身份图片，并点击“创建 OBS 浏览器源”。直接启动摄像头时系统也会自动创建。
4. 复制生成的完整 HTTPS 地址。地址中 `#` 后的短时凭据只保存在当前页面，不会进入 nginx 或后端访问日志。
5. 启动摄像头。GPU 返回的换脸帧会由后端直接写入远端输出，不经过浏览器二次上传。
6. 展开“目标音色与全双工对话”，选择音色并开始会话。AI 回答音频会进入同一远端输出。

绑定 OBS 时“本地监听”默认关闭，防止同一段回答在 OBS 与本机扬声器重复播放。需要本机监听时可手动开启，建议佩戴耳机避免回声重新进入麦克风。

### OBS 端

1. 在 OBS 的“来源”中点击 `+`，选择“浏览器”。
2. 把 Sere1nFish 复制的完整地址粘贴到 URL。
3. 宽度填写 `1280`，高度填写 `720`；保持原始比例，不拉伸画面。
4. 启用“通过 OBS 控制音频”，在 OBS 混音器确认该浏览器源有电平。
5. 建议关闭“场景不可见时关闭源”，避免切换场景后重新建连。
6. 点击“启动虚拟摄像机”，在微信、会议软件或浏览器中选择 `OBS Virtual Camera`。

macOS 首次使用 OBS 虚拟摄像机、麦克风或屏幕来源时，按系统提示在“系统设置 -> 隐私与安全性”中授权；修改权限后重启 OBS。浏览器源本身只需出站访问 Sere1nFish 的 HTTPS/WSS `443`。

### 输出会话安全

- 输出会话默认有效 8 小时，最长 12 小时；关闭输出后地址立即失效。
- 每个用户最多同时创建 4 个输出，每个输出最多 4 个观看端。
- 地址凭据使用高熵随机值，服务端只保留 SHA-256 摘要，不写 MongoDB、配置、日志或 Git。
- OBS 只订阅合成后的图片帧和 PCM 音频，不接触身份原图、麦克风原始音频或第三方凭据。
- 当前媒体总线是实时低延迟输出，不做录制和持久化。

## 3. 快速排查

| 现象 | 检查项 |
| --- | --- |
| 麦克风无法启动 | 页面必须是 HTTPS；检查 Chrome 网站权限和系统麦克风权限 |
| 语音有回声或自己打断自己 | 使用耳机，或切换为“按住说话” |
| 无法选择扬声器 | Chrome/系统不支持输出设备切换时会使用系统默认设备 |
| OBS 页面提示地址失效 | 在 Sere1nFish 重新创建输出并替换浏览器源 URL |
| OBS 无法打开 HTTPS 地址 | 使用有效公网证书，并确认本机能直接访问该 Sere1nFish 地址 |
| OBS 一直等待画面 | 确认实时摄像头已启动、GPU 在线，并保持控制页开启 |
| OBS 有画面无声音 | 启用“通过 OBS 控制音频”，展开全双工对话并确认 AI 已产生回答 |
| 声音重复或触发回声 | 关闭“本地监听”或佩戴耳机，检查 OBS 音频监听未重复输出 |
| OBS 切换场景后断流 | 关闭“场景不可见时关闭源”，或在来源属性中手动刷新缓存 |
| 全双工返回 503 | 检查 `cosyvoice.api_key`、Workspace、区域和 WSS 地址 |
